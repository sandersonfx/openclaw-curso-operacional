🏗️ Módulo 2 — Estrutura de Agentes

25 min Estrutura Nível: Iniciante

O que você vai construir

Uma equipe de agentes de IA — cada um especialista na sua área, orquestrados pelo COO.

🎯 Objetivos

  1. Entender o modelo COO + Especialistas
  2. Criar AGENTS.md com 2-3 agentes para o seu negócio
  3. Definir autonomia com clareza (o que pode, o que confirma, o que nunca faz)
  4. Configurar roteamento de comandos
  5. Testar delegação entre agentes

1. Por que Múltiplos Agentes?

Um COO sozinho faz tudo, mas faz meia-boca. A arquitetura certa é COO orquestra, especialistas executam.

VOCÊ (empreendedor)
  │
  └── COO DIGITAL (orquestrador)
       │
       ├── AGENTE DE MARKETING → Tráfego + Social
       ├── AGENTE DE VENDAS → CRM + Follow-up
       └── AGENTE DEV → Código + Infra
🎯 Regra de ouro: Se um agente pode fazer sozinho, não passa pelo COO. COO só entra quando precisa decidir, coordenar ou escalar. Isso reduz gargalo e acelera tudo.

3. A anatomia de um agente bem definido

Um agente bom tem 5 blocos no AGENTS.md:

## ANA — Traffic Manager (Tráfego Pago)

### Papel
Gerencia campanhas de tráfego pago (Meta Ads, Google Ads, TikTok).

### Responsabilidades
- Gerenciar campanhas de tráfego pago
- Otimizar CPA e ROAS diariamente
- A/B testar audiences, criativos, landing pages
- Reportar ROI/performance diariamente

### Autonomia
ANA pode fazer sozinha:
- Pausar campanha com CPA alto
- Testar nova audiência (dentro do orçamento)
- Escalar campanha que está convertendo bem

ANA deve confirmar antes de:
- Aumentar budget total em mais de 50%
- Mudar criativo principal
- Mudar público-alvo estratégico

### Métricas
- CPA: Target menor que R$X
- ROAS: Target maior que 3x
- CTR: Target maior que 2%

### Stack / Ferramentas
- Meta Ads API, Google Ads API
- Pixel tracking e conversões
🔥 Dica: Autonomia bem definida é o que separa agente útil de agente perigoso. Sempre use verbos de ação: "pode pausar", "deve confirmar", "nunca deleta".

4. Matriz de Autonomia

NívelSignificadoExemplo real
🟢 PodeFaz sem perguntarPausar anúncio se CPA > R$100
🟡 ConfirmaFaz mas pede OK antesAumentar budget total em +50%
🔴 NuncaNem sugereDemitir alguém, pagar fornecedor
⚠️ Cuidado: Autonomia vaga gera problema. "Pode tomar decisões" é perigoso. "Pode pausar campanha se CPA > R$100 por 3 dias seguidos" é seguro.

5. Criando um Novo Agente

# 1. Criar pasta do agente
mkdir -p ~/.openclaw/agents/nome-do-agente/agent

# 2. Criar SOUL.md do agente
nano ~/.openclaw/agents/nome-do-agente/agent/SOUL.md

# 3. Adicionar ao AGENTS.md do COO
nano ~/.openclaw/workspace/AGENTS.md

# 4. Reiniciar o gateway
openclaw gateway restart

# 5. Testar: mande um comando no Telegram
/nomedoagente Faça X

6. Delegação Automática

Com o AGENTS.md bem definido, o COO sabe quando delegar automaticamente.

Exemplo: Você manda "Como tá o CPA das campanhas essa semana?" → COO detecta tráfego → delega pra ANA → ANA consulta dados, responde → COO repassa com contexto.

Outro: "O site caiu?" → COO delega pra LEO → verifica uptime, logs → responde "Site no ar, último deploy foi X".

✅ Checklist do Módulo 2

  • AGENTS.md criado com 2-3 agentes específicos pro seu negócio
  • Cada agente tem: Papel, Responsabilidades, Autonomia, Métricas
  • Autonomia definida com ações concretas (não genéricas)
  • Roteamento de comandos testado
  • COO delega corretamente para especialistas

🔧 Troubleshooting

"COO não delega": revise o AGENTS.md. As responsabilidades precisam ser específicas. "Marketing" é vago. "Meta Ads — otimização de CPA e ROAS" é claro.

"Agente não responde": verifique se a pasta foi criada em ~/.openclaw/agents/ e reiniciou o gateway.

"Muitos agentes": comece com 1 COO + 2 agentes no máximo.
