# 🧠 Monte seu COO Digital em 2 Horas

**OpenClaw Operacional** — Curso prático para empreendedores.

Sem teoria. Sem enrolação. Você sai daqui com um COO digital funcionando no seu WhatsApp ou Telegram.

---

## Como usar este curso

1. Clone este repositório: `git clone [URL]`
2. Abra o `index.html` no navegador
3. Siga os módulos em ordem
4. Preencha os templates da pasta `template-aluno/` conforme avança
5. No final do Módulo 4, você tem um COO operando

## O que você vai construir

```
VOCÊ (empreendedor)
  │
  └── COO DIGITAL (OpenClaw)
        │
        ├── AGENTE DE TRÁFEGO (Meta/Google Ads)
        ├── AGENTE DE SOCIAL MEDIA
        ├── AGENTE DE DEV
        └── SKILLS (Financeiro, RH, Demandas)
```

## Pré-requisitos

- Um computador (Linux, Mac, ou Windows com WSL)
- Node.js 18+
- Uma conta no Telegram (recomendado) ou WhatsApp Business
- 2 horas
