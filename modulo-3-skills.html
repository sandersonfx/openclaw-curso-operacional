🎯 Módulo 3 — Skills Práticas

30 min Skills Nível: Intermediário

O que você vai construir

Sua primeira skill — o manual financeiro que seu COO carrega quando precisa tomar decisão sobre dinheiro.

🎯 Objetivos

  1. Entender o que é uma skill e quando criar
  2. Dominar a anatomia de uma skill (SKILL.md + referências + assets)
  3. Criar skill financeira com dados reais do seu negócio
  4. Aprender Progressive Disclosure — carregar só o necessário

1. O que é uma Skill?

Skill = manual de operação modular. O COO carrega a skill relevante quando precisa — sem poluir a memória com o que não está em uso.

❌ Sem skill

COO não sabe seu Plano de Contas. Toda vez que você pergunta "qual a margem?", ele improvisa.

✅ Com skill

COO carrega o manual financeiro automaticamente. Responde com números reais.

🧠 Analogia: Skill está pro COO assim como POP (Procedimento Operacional Padrão) pra um funcionário novo. Só abre quando precisa.

🎯 Regra prática: Se você repete a mesma informação 3x pro COO → vira skill. Se o COO executa a mesma tarefa todo dia → vira agente.

4. Skill Financeira — Passo a Passo

Frontmatter (DISPARADOR)

---
name: meu-negocio-financeiro
description: Gestão financeira do [SEU NEGÓCIO] 
  — fluxo de caixa, Plano de Contas, custos fixos e 
  variáveis, margem de lucro, projeções. Usar quando 
  precisar: fechar mês, revisar custos, calcular 
  margem, definir preço, aprovar investimento.
---
🔥 Crítico: A description precisa listar TODOS os gatilhos de uso. Quanto mais específica, mais o COO acerta quando carregar.

Corpo — Dados reais

## Plano de Contas

### Faturamento Base
R$ 50.000/mês (alvo operacional)

### Custos Variáveis
| Item | % do faturamento |
|------|-------------------|
| Custo do produto (CMV) | 30% |
| Comissão marketplace | 5% |
| Frete | 7% |
| Total variável | 47% |

### Custos Fixos (mensal)
| Categoria | Valor |
|-----------|-------|
| Pessoal | R$ 8.000 |
| Infra | R$ 3.500 |
| Marketing | R$ 3.000 |
| Total fixo | R$ 16.000 |

### Margem e Lucro
Faturamento: R$ 50.000
(-) Custos variáveis (47%): R$ 23.500
(=) Margem de contribuição: R$ 26.500 (53%)
(-) Custos fixos: R$ 16.000
(=) Lucro líquido: R$ 10.500 (21%)

Sistema de Alertas

🔴 Vermelho — Alerta Imediato
- Faturamento abaixo de 80% da meta
- Margem de contribuição abaixo de 48%
- Lucro líquido abaixo de R$ 5.000
- Caixa cobre menos de 15 dias de custo fixo

🟡 Amarelo — Monitorar
- Faturamento entre 80-90% da meta
- Variação maior que 15% em qualquer custo

🟢 Verde — Saudável
- Todos os indicadores dentro do alvo
