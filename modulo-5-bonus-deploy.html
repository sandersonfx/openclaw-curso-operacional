🚀 Módulo Bônus — Deploy 24/7

10 min Bônus Nível: Intermediário

O que você vai fazer

Tirar o COO do seu notebook e colocar num servidor que roda 24 horas por dia, 7 dias por semana.

🎯 Por que deploy?

  • Seu computador desliga → COO morre
  • Servidor na nuvem → COO sempre online
  • Daily checkpoints rodam mesmo se você estiver dormindo
  • Alertas chegam em tempo real, não quando você abre o notebook

Opção 1 — VPS (Recomendado)

DigitalOcean Droplet ~$6/mês

Melhor custo-benefício pra começar. 1GB RAM, 25GB SSD, Ubuntu.

# 1. Criar droplet na DigitalOcean (Ubuntu 22.04)
# 2. Conectar no servidor
ssh root@[IP_DO_SERVIDOR]

# 3. Instalar Node.js
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs

# 4. Instalar OpenClaw
npm install -g openclaw

# 5. Copiar workspace (no seu computador local)
scp -r ~/.openclaw/workspace root@[IP]:/root/.openclaw/workspace

# 6. Iniciar com PM2 (reinicia automaticamente)
npm install -g pm2
pm2 start openclaw -- gateway start
pm2 save
pm2 startup

# Pronto. Seu COO tá online 24/7.

Opção 2 — Hetzner (Alternativa)

Hetzner CX22 ~€4/mês

2GB RAM, 40GB SSD. Mesmo processo da DigitalOcean.

Opção 3 — Raspberry Pi em Casa

Raspberry Pi 4 ~R$ 400 (hardware)

Custo zero mensal. Desvantagem: se cair a luz, cai o COO.

# No Raspberry Pi
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs
npm install -g openclaw pm2
pm2 start openclaw -- gateway start
pm2 save && pm2 startup

Manutenção Semanal (5 min)

# 1. Verificar se tá online
openclaw status

# 2. Verificar logs de erro
pm2 logs openclaw --lines 20

# 3. Atualizar OpenClaw
npm update -g openclaw
pm2 restart openclaw

# 4. Rodar security audit
openclaw secrets audit

Checklist de Segurança (OBRIGATÓRIO)

  • Firewall ativo (ufw enable, só porta SSH e OpenClaw abertas)
  • SSH só com chave, sem senha
  • OpenClaw gateway bind em localhost (não exposto publicamente)
  • Backup diário do workspace
  • Secrets audit rodou sem novidades
⚠️ Cuidado: Nunca exponha o gateway OpenClaw diretamente na internet sem autenticação. Use Tailscale, VPN, ou mantenha bind em localhost.
