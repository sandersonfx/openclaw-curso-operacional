⚡ Módulo 4 — Operação Diária

20 min Operação Nível: Iniciante

O que você vai construir

A rotina diária do seu COO — checkpoint manhã/noite, sistema de memória, alertas e autonomia progressiva.

🎯 Objetivos

  1. Configurar o Daily Checkpoint (manhã e noite)
  2. Dominar o ciclo de memória (extrair antes de compactar)
  3. Ativar alertas automáticos
  4. Primeira semana de operação real

1. Daily Checkpoint

🌅 07:00 — Checkpoint da Manhã
  1. Qual o foco principal hoje?
  2. Top 3 prioridades?
  3. Algum bloqueador?
  4. Precisa delegar algo?
  5. Alguma decisão pendente?
  6. Reunião ou compromisso importante?
  7. Meta do dia?
  8. Precisa de mim pra algo específico?
🌙 21:00 — Checkpoint da Noite
  1. O que foi feito vs planejado?
  2. Onde perdeu tempo?
  3. 1 coisa boa do dia (gratidão)
  4. 3 ações prioritárias pra amanhã
  5. Produtividade de 0-10?
🎯 Benefício: Em 1 semana, seu COO tem dados pra identificar padrões — onde você perde tempo, o que sempre fica pra depois, qual dia é mais produtivo.

2. Sistema de Memória

⚠️ NUNCA COMPACTAR SEM EXTRAIR PRIMEIRO. Se não estiver em arquivo, não existe na próxima sessão.

Arquivos de memória

ArquivoO que guardaQuando atualizar
MEMORY.mdEstado atual, métricas, agentesQuando algo MUDAR
memory/context/decisions.mdDecisões permanentesAo tomar decisão
memory/context/lessons.mdErros e acertosAo aprender algo
memory/context/pending.mdO que tá travadoQuando surgir bloqueio
memory/projects/*.mdStatus de cada projetoSemanal

Checklist de Extração

  1. Extrair decisões → memory/context/decisions.md
  2. Extrair lições → memory/context/lessons.md
  3. Extrair pendências → memory/context/pending.md
  4. Atualizar projetos → memory/projects/*.md
  5. Atualizar MEMORY.md
  6. Só depois: compactar contexto

3. HEARTBEAT.md

# HEARTBEAT.md

## Checklist de consolidação
1. verificar se existe algo impactando faturamento
2. revisar pendências
3. atualizar projetos ativos
4. promover decisões e lições para os arquivos

## Crons de proteção
- Watchdog (15 min): monitora crons, retry 3x
- Backup (03:30): backup workspace + push git
- Security audit (domingo): auditoria semanal

4. Alertas Automáticos

Ocupação baixaAgenda < 60% nos próximos 7 dias🟡 Monitorar
Cron falhou3 tentativas sem sucesso🔴 Imediato

5. Primeira Semana Real

Dia 1-2 — Conhecer

COO aprende o negócio. Você responde perguntas. Skills são carregadas. Memória começa a construir.

Dia 3-4 — Sugerir

COO começa a fazer sugestões baseadas nos dados. Feedback loop ativo.

Dia 5-7 — Operar

COO opera com autonomia. Daily checkpoints fluindo. Alertas automáticos.

🔥 O segredo: Use o COO todo dia. Um COO usado 1x por semana é um assistente glorificado.

6. Sistema Proteção

ProteçãoProblema que previne
