# 🧠 Monte seu COO Digital

> Este repositório é seu ponto de partida. Preencha os arquivos com `[TEXTO]` conforme avança no curso.
> No final, você terá seu COO digital operando.

## Estrutura

```
meu-codigo/
├── SOUL.md              ← Personalidade do COO (quem é, como opera)
├── IDENTITY.md          ← Nome, gênero, emoji
├── USER.md              ← Seus dados e prioridades
├── AGENTS.md            ← Estrutura de agentes da sua empresa
├── MEMORY.md            ← Estado atual do negócio
├── HEARTBEAT.md         ← Rotina de consolidação
├── skills/
│   └── meu-negocio-financeiro/
│       ├── SKILL.md     ← Sua primeira skill (financeira)
│       └── references/  ← Documentos de apoio
└── memory/
    ├── context/         ← Decisões, lições, pendências
    └── projects/        ← Status de cada projeto
```

## Como usar

1. **Módulo 1:** Preencha `SOUL.md`, `IDENTITY.md`, `USER.md`
2. **Módulo 2:** Preencha `AGENTS.md`
3. **Módulo 3:** Preencha `skills/meu-negocio-financeiro/SKILL.md`
4. **Módulo 4:** Preencha `MEMORY.md` e configure a rotina diária

Cada arquivo tem placeholders `[ASSIM]` — é só substituir.
