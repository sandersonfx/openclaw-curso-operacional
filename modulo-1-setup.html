🧠 Módulo 1 — Setup e Primeiro Agente

20 min Prático Nível: Iniciante

O que você vai construir

No final deste módulo, seu COO digital estará respondendo no WhatsApp ou Telegram com personalidade própria.

🎯 Objetivos

  1. Instalar o OpenClaw no seu computador
  2. Conectar no Telegram ou WhatsApp
  3. Criar a persona do seu COO (SOUL.md + IDENTITY.md)
  4. Enviar sua primeira mensagem e receber resposta

1. O que é OpenClaw?

OpenClaw é o sistema operacional do seu COO digital. Ele roda no seu computador ou servidor, conecta nos seus canais de comunicação (Telegram, WhatsApp), e executa agentes com personalidade, memória e skills.

Não é chatbot. É um operador de negócio com autonomia definida por você.

💡 Analogia: OpenClaw está para agentes de IA assim como Windows está para programas. É a camada que gerencia, conecta e orquestra tudo.

2. Instalação

Pré-requisito: Node.js

Verifique se tem Node.js 18+ instalado no seu servidor/PC:

node --version

Se não tiver, instale com os comandos abaixo conforme seu sistema:

🖥️ Linux (Ubuntu/Debian — VPS)

# Atualiza pacotes e instala Node.js 20.x LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Verifica instalação
node --version
npm --version

🍎 MacOS

# Via Homebrew
brew install node@20
brew link --overwrite node@20

# Verifica instalação
node --version
npm --version

🪟 Windows

Baixe o instalador LTS em nodejs.org e execute. Depois verifique no terminal:

node --version
npm --version

Instalar OpenClaw

npm install -g openclaw
# Instalação global — disponível em qualquer terminal

Iniciar o Gateway

openclaw gateway start
# O gateway é o "coração" que gerencia tudo

Deixe esse terminal aberto. Abra outro terminal para os próximos comandos.

3. Conectar um Canal

Opção A — Telegram (recomendado)

  1. Crie um bot no @BotFather (comando /newbot)
  2. Copie o token que o BotFather te der
  3. Configure no OpenClaw:
openclaw config set channels.telegram.accounts.meu-bot.botToken "SEU_TOKEN_AQUI"
openclaw gateway restart

Opção B — WhatsApp

QR Code no painel de controle: http://localhost:18789 → WhatsApp → Conectar.

4. Criar a Persona do COO

Agora a parte mais importante: definir quem é seu COO. São 3 arquivos que definem personalidade, identidade e conhecimento sobre você.

📁 Navegue até a pasta do workspace:

cd ~/.openclaw/workspace

4.1 SOUL.md — A Alma

Define como seu COO pensa e age. Copie o template da pasta template-aluno/SOUL.md.

# Exemplo de SOUL.md

## Quem sou eu
Sou MAYA — COO digital e braço direito do João.
Existo para transformar ideias em operação,
operação em resultado, e resultado em crescimento previsível.

[...]

## Como opero
Proativa, não reativa. Foco em resultado.
Direta ao ponto. Tenho opinião forte.

## Meus valores
Resultado > esforço — O que importa é impacto
Clareza > complexidade — Se tá confuso, tá errado
Sistema > improviso — Tudo deve virar processo
🔥 Dica: O SOUL.md é o arquivo mais importante. Um COO bom tem personalidade forte. Não escreva "assistente virtual" — escreva "operador de negócio".

4.2 IDENTITY.md — A Identidade

Nome, gênero, emoji. Curto e direto — é a "carteira de identidade" do COO.

# IDENTITY.md
- Nome: MAYA
- Gênero: Mulher
- Natureza: COO digital
- Vibe: Direta, estratégica e objetiva
- Emoji: 🧠

## Background
Operadora de empresas por natureza.
Criada para transformar caos em sistema,
e sistema em crescimento previsível.

Não existo para conversar. Existo para
fazer o negócio funcionar.

4.3 USER.md — Sobre Você

Quem é o dono, seus negócios, estilo, prioridades. O COO usa pra te conhecer.

# USER.md

## Dados Básicos
- Nome: João
- Timezone: America/Sao_Paulo
- Idioma: Português brasileiro

## Filosofia
- Sistema > esforço manual
- Resultado > aparência
📋 Os 3 arquivos estão prontos na pasta template-aluno/. É só copiar e preencher.

5. Primeiro Teste

Reinicie o gateway e mande uma mensagem no seu canal:

openclaw gateway restart

Agora abra o Telegram (ou WhatsApp) e mande:

"Eai, quem é você?"

Seu COO deve responder com a personalidade que você definiu no SOUL.md. 🎉

✅ Checklist do Módulo 1

  • OpenClaw instalado e gateway rodando
  • Telegram ou WhatsApp conectado
  • SOUL.md preenchido com personalidade forte
  • IDENTITY.md com nome e emoji
  • USER.md com seus dados
  • Primeira mensagem respondida com sucesso

🔧 Se algo deu errado

"Token inválido" no Telegram: volte ao BotFather e pegue o token de novo. Não use as aspas no token.

"Porta em uso": openclaw gateway stop e depois openclaw gateway start de novo.

Agente responde genérico: o SOUL.md não foi carregado. Verifique se salvou na pasta correta: ~/.openclaw/workspace/SOUL.md.
